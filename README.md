# Theocracy-Release

Theocracy 的发布通道仓库 —— `version.json` 与 APK 产物由开发仓库
([Ultra-Guru/Theocracy](https://github.com/Ultra-Guru/Theocracy)) 的 CI 自动维护。

- `version.json`：应用内更新检查的固定入口
  `https://raw.githubusercontent.com/Ultra-Guru/Theocracy-Release/main/version.json`
- Releases：完整 APK / 增量补丁（VCDIFF）资产

本仓库不接受手工提交。
